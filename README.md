# ¡Hola! Soy Juan Martín 👋

## 👨‍💻 Sobre mí

Soy estudiante de **Ingeniería en Sistemas de Información** en la **Universidad de la Cuenca del Plata**, con especial interés en el **desarrollo web**, el **testing y la calidad de software**.

A través de proyectos académicos y personales he trabajado en distintas etapas del desarrollo de software: frontend, backend, APIs, bases de datos, testing, automatización, integración continua, contenedores y despliegue.

Muchas de las tecnologías y herramientas que utilizo las fui incorporando a medida que cada proyecto planteaba nuevos desafíos, fortaleciendo especialmente mi capacidad de **aprendizaje autónomo y continuo**.

Me interesa seguir creciendo en desarrollo web y calidad de software, aunque disfruto explorar nuevas tecnologías y áreas dentro de Sistemas. Me caracterizo por la **responsabilidad**, la **predisposición** y las ganas de seguir aprendiendo y creciendo profesionalmente dentro de un equipo.

## 🧩 Otros Proyectos

### 🐍 Análisis Numérico con Python

Proyecto desarrollado en Python para trabajar con distintos métodos de análisis numérico, incluyendo:

- resolución de ecuaciones diferenciales mediante **Runge-Kutta de cuarto orden**;
- interpolación de resultados;
- cálculo de autovalores y autovectores mediante el **método de potencia inversa**;
- pruebas automatizadas de los algoritmos implementados.

**Tecnologías:** Python · NumPy · unittest
